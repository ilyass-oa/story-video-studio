# 08 · Bank builder (design mode — deliberate, reviewed, rare)

Episodes are only as good as the bank. Extending it is real design work: do it slowly, render a
gallery, get the user's approval, then it becomes locked for every future episode.

## Where things live
| Bank | Files | Contract |
|---|---|---|
| look packs | `engine/src/packs.ts` | colours, fonts, sizes, grade, overlays, transition rotation |
| templates | `engine/src/templates/index.tsx` + `catalog.json` | component + slots/variants/limits |
| layers | `engine/src/layers/*` (Backdrop, Overlays, Media, SceneShell) · `engine/src/text/KineticText.tsx` | shared building blocks |
| textures | `banks/textures/` (generated by `tools/py/make_textures.py`, seeded) | grain, smoke, paper, window shadows, dust |
| devices | `banks/devices/` + `index.json` (`./sv device add`) | cutout + screen rect |
| images | `banks/images/` + `index.json` (`./sv img promote`) | reusable cutouts/photos with tags + licence |
| sfx / music | `banks/sfx|music/<category>/` + `index.json` + `wishlist.json` (`./sv sfx fetch`, `./sv sfx build`) | normalised, peak-measured |

## Adding a template (checklist)
1. Start from a reference frame (put it in a local `references/` folder — git-ignored, never published). Describe layers: background / far / subject / text / overlays.
2. Build it only from existing layers (`Cutout`, `FullMedia`, `PhotoCard`, `DeviceWithScreen`, `Phone`,
   `BigWord`, `KineticText`, `PushPin`, `PaperClip`) + pack tokens. No hard-coded colours or fonts —
   read them from the pack so it works in every pack.
3. Everything time-based uses `useCurrentFrame()` and word frames (`firstAt`, `wordAt`); no
   `Math.random`, no CSS animations, no timers.
   Engine rules learned the hard way: wrap any 3D-transformed media (rotateX/Y cards, panels) in
   `<Flat3D>`; keep text columns geometrically clear of photos (dark script on a photo disappears);
   script fonts overhang their glyph box — never clip text at its box edge; text size comes from the
   pack × template (`scale`, `fill`), never from episodes.
4. Register in `TEMPLATES` and describe it in `catalog.json` (`use`, `slots`, `variants`, `maxWords`,
   `maxLineChars`, `minSeconds`). The `use` text is what agents read to choose it — be precise.
5. Add auto-sfx for its entrance in `TEMPLATE_SFX` (tools/lib/compile.mjs) if it has a physical action.
6. `npx tsc --noEmit` in `engine/`, add a sample to `SAMPLES` in `tools/lib/gallery.mjs`, run
   `./sv gallery`, compare with the reference in both packs, iterate, and show the user before calling it done.

## Adding a theme (preferred over a new pack)
A theme re-colours a pack without touching layouts: add its tokens to `THEMES` in `engine/src/packs.ts`
(colours, optional accent font from `fonts.ts`, grade, `atmos` — glow, smoke tint, backlight, flash,
beam, spot, light, line), its entry in `engine/src/looks.json` (pack, default backdrop, label, when to
use it), and its two art styles in `ART_STYLES` (`tools/lib/assets.mjs`). Then render EVERY template in
it (`looks({only: [id], templates: all, outDir})` from `tools/lib/gallery.mjs`) and check each frame for
clipped or unreadable text, then `./sv looks`. A new backdrop = a branch in `layers/Backdrop.tsx` + its
entry in `looks.json → backdrops`. Never hard-code a colour in a template: use `pack.colors` / `pack.atmos`.

## Adding a pack
Copy a pack in `packs.ts`, change tokens only (colours, fonts from `engine/src/fonts.ts`, grade,
overlays, transitions, atmos). Fonts must be local (@fontsource) — add the import + face to `fonts.ts`.

## SFX bank
`banks/sfx/wishlist.json` is the recipe (id, category, query, tags, duration window, variants, loop).
`./sv sfx build` is idempotent — only missing variants are fetched. `--force` refetches. To import a
local library (e.g. Sonniss GDC bundle), convert with `tools/py/audiokit.py sfx IN OUT` and add index
entries with `group`, `category`, `tags`, `duration`, `peak`, `license`, `source`.
